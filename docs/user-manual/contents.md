# User Manual — TeamUp

> **TeamUp** is a platform for managing coding events designed for RIWI. It enables team creation, automatic GitHub repository management, deliverable evaluation, and progress tracking for participants.

## System Roles

```
TeamUp
├── ADMIN              → Manages events and global configuration
├── CODER              → Participates in events and creates or joins teams
├── TL_DEVELOPMENT     → Evaluates technical aspects of projects
├── TL_SOFT_SKILLS     → Evaluates soft skills and collaboration
└── TL_ENGLISH         → Evaluates English proficiency
```
