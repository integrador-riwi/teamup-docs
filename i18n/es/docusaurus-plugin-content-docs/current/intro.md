# Introducción

**TeamUp** es una plataforma SaaS full-stack diseñada para gestionar hackathons, capstone y competencias de programación. Proporciona herramientas para la gestión de eventos, la formación de equipos, la evaluación de proyectos y el voto en vivo del público.

## ¿Qué hace TeamUp?

- **Gestión de eventos** — Crea y administra hackathons, capstones y talleres.
- **Formación de equipos** — Los coders se unen a equipos y los TL los gestionan y evalúan.
- **Ranking y evaluación** — Los líderes de equipo califican proyectos con rúbricas.
- **Votación en vivo** — El público vota mediante códigos QR en tiempo real.
- **Finalistas y podio** — Calcula automáticamente los ganadores combinando puntuaciones y votos.

## ¿Quién lo usa?

| Rol | Descripción |
|------|-------------|
| `ADMIN` | Acceso completo a la plataforma, gestiona eventos y usuarios |
| `STAFF` | Puede gestionar eventos |
| `TL_DEVELOPMENT` | Evalúa proyectos de desarrollo |
| `TL_SOFT_SKILLS` | Evalúa habilidades blandas |
| `TL_ENGLISH` | Evalúa habilidades de inglés |
| `CODER` | Se une a equipos y envía proyectos |

## Stack tecnológico

| Capa | Tecnología |
|-------|-----------|
| Frontend | SPA de JavaScript sin framework |
| Backend | Node.js + Express |
| Base de datos principal | PostgreSQL |
| Base de datos secundaria | MongoDB |
| Tiempo real | Socket.IO |
| Autenticación | JWT + OAuth de GitHub |
| Subida de archivos | Cloudinary |
| Despliegue frontend | Vercel |
| Despliegue backend | Railway |
